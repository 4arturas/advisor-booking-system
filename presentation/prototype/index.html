Node-RED Flows

The prototype is built as visual flows in Node-RED.

API Booking Flow

POST /api/bookings — Atomic CTE with FOR UPDATE SKIP LOCKED

Single atomic query handles locking, insertion, and slot marking — no race conditions

Availability Check Flow

GET /api/availability/:advisorId?date=YYYY-MM-DD

Database Init Flow

Creates tables and seeds 80 booking slots (Mon-Fri, 9-17h, 2 advisors)

Race Condition Handling

Atomic CTE Query:


WITH target_slot AS (
  SELECT id FROM booking_slot
  WHERE advisor_id = $1
    AND start_time = $2
    AND is_booked = false
  FOR UPDATE SKIP LOCKED
),
reservation AS (
  UPDATE booking_slot
  SET is_booked = true
  WHERE id IN (SELECT id FROM target_slot)
  RETURNING id
)
INSERT INTO booking (...)
SELECT ... WHERE EXISTS (
  SELECT 1 FROM reservation
)
RETURNING id;

Three-Layer Protection:

  1. Redis TTL — Slot marked "reserved" for 5 min
  2. DB Lock — FOR UPDATE SKIP LOCKED
  3. Unique Constraint — (advisor_id, start_time, end_time)

What Customer A Sees (Wins)

  1. Slot reserved in Redis
  2. Database row locked
  3. Calendar event created
  4. Booking saved to PostgreSQL
  5. Email published to RabbitMQ
  6. "Booking confirmed!"

What Customer B Sees (Loses)

  1. Sees slot as "reserved" in Redis
  2. Waits for database lock
  3. Slot now marked as booked
  4. "Sorry, this time slot was just taken. Please choose another."

Email Notification Service

Flow:

  1. Booking confirmed → publish to booking-exchange
  2. Consumer reads from email-notification-queue
  3. Sends confirmation email via Microsoft Graph API
  4. Success: acknowledge message
  5. Failure: retry with exponential backoff

Retry Strategy:

  • Attempt 1: 4 seconds
  • Attempt 2: 8 seconds
  • Attempt 3: 16 seconds
  • All failed → Dead Letter Queue

Prometheus Metrics:

  • nr_email_received_total

Initial Setup

  1. Open Node-RED editor at http://localhost:1880
  2. Go to "Database Init" tab
  3. Click the "Initialize DB" inject button
  4. Check debug sidebar for "Tables Created" and "Slots Inserted"

Test the API


# Check availability
curl http://localhost:1880/api/availability/1?date=2026-07-14

# Book a slot
curl -X POST http://localhost:1880/api/bookings \
  -H "Content-Type: application/json" \
  -d '{"advisorId":1,"customerName":"John Doe","customerEmail":"john@example.com","slotId":1}'
